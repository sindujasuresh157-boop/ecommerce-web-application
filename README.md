# 🛍️ ShopEasy - E-Commerce Web Application

ShopEasy is a simple E-Commerce Web Application built as an internship project.

## ✨ Features

- 🛍️ Product catalog
- 🛒 Add products to cart
- ➕ Increase/decrease product quantity
- 🗑️ Remove products from cart
- 💳 Checkout
- 📦 Order placement
- 🔐 User/Admin login interface
- 🗄️ Supabase database integration
- 📱 Responsive web design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Supabase
- PostgreSQL Database
